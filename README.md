# karin-plugin-glory-of-kings

王者荣耀营地查询插件（Karin 版）。

本仓库是 [GloryOfKings-Plugin](https://github.com/cchanlan/GloryOfKings-Plugin) 的 **Karin 适配版** ——
同一份业务代码（`apps/` + `utils/`），外面套了一层兼容层，让它能在 Karin 上跑。

## 安装

```bash
# 在 karin 根目录下
cd plugins
git clone https://github.com/cchanlan/karin-plugin-glory-of-kings.git
cd ..
pnpm i
```

重启 karin 即可。启动日志里会有一行：

```
[王者插件] 加载完成：模块 40 个 · 插件类 40 个 · 指令 103 条 · 定时任务 10 个
```

出图依赖 karin 的渲染器插件，没装的话先装：

```bash
pnpm add @karinjs/plugin-puppeteer
```

| 指令 | 说明 |

## 配置

配置文件在 `config/default_config/`（模板）与 `config/config/`（你的实际配置，首次运行自动生成）。

出图格式、推送间隔、共享库地址等都在 `config.yaml` 里，改动即时生效。

## 适配说明（给想改代码的人）

**业务代码（`apps/` 与 `utils/`）与 Yunzai 版完全一致**，一个字都没改。
Karin 适配全部在 `lib/compat/` 这一层：

| 文件 | 作用 |
|---|---|
| `globals.js` | 注入云崽全局（`plugin` / `segment` / `Bot` / `puppeteer` …） |
| `loader.js` | 扫 `apps/`，把云崽插件类的 `rule`/`task` 翻译成 Karin 的命令与定时任务 |
| `event.js` | 事件适配（`e.reply` 签名、`e.group`/`e.friend` 门面、`e.at` 语义…） |
| `segment.js` | 消息段适配（按钮的 callback/input → Karin 的 keyboard） |
| `bot.js` | `globalThis.Bot` 门面（`gl`/`gml`/`pickGroup`/`sendMasterMsg`…） |
| `render.js` | 出图 shim（云崽的 `puppeteer.screenshot` → Karin 的 `render.render`） |
| `plugin.js` | 云崽插件基类 |
| `common.js` / `update.js` / `dataInit.js` | `common`、`update` 的替身与数据文件初始化 |

`karin-apps/index.js` 是唯一的 `karin.apps` 目录 —— 它把 `lib/compat/registry.js`
里的命令对象导出给 Karin（Karin 只认「模块导出里的命令」）。
